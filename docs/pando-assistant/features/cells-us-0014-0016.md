# Agents as cells, side card, actions and target (PDA-US-0014/15/16)

Part of [[pando-assistant/plans/backlog-execution_plan.md]]. Builds on [[pando-assistant/features/organism-view-us-0011.md]], [[pando-assistant/changes/pando-client-api-layer.md]] and docs/06-ui-mapping.md.

## What changed
- Pure core in `crates/app/src/cells/`: `mapping` (engine/status/label tables, custom engine templates), `source` (CellSource: poll to cells, birth, Delegating, 10 s removal, instances, synthetic primary Waiting cell), `time`, `card` (side card model + allowed actions), `target` (Hablarle / Esc / primary), `new_agent` (create form), `actions` (cancel, delete, relaunch, create, classify 409/404, deliver ledger answers).
- Async: `poller` (1 s visible / 5 s hidden, follows `ConnectionHub::subscribe()`, replaced later by the G1 stream).
- GPUI: `pane::OrganismPane` (organism + side card + form + target + approvals) mounted in `MainView`; header project / target / "?" pills.
- Approvals: only through `pando_client::approvals::Approvals` with `Origin::Explicit`; requests the server stops listing are denied locally and never sent.

## Files
`crates/app/src/cells/*`, `views/main_view.rs` (pane + pills, small additive edit), `connection.rs` (stable `subscribe()` snapshot receiver), `app.rs` (`cells::pane::bind_keys`), locale `organism.{es,en}.yml` (`cells.*`).

## Verification
`cargo test -p app` (89 pass), clippy `-D warnings`, `cargo xtask check-deps`; end to end on xvfb against a Python mock Pando (cells from tasks/instances, card, Approve delivered as `allow`, Hablarle pill). Not verified: typing into the create form via X events, a real Pando, real screen reader.
