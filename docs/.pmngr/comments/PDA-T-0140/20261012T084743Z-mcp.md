`VoiceService` runs `audio::bargein::BargeIn` per 20 ms frame (energy VAD `voice/vad.rs` on the echo-cleaned signal; sonora AEC via the app feature `echo-cancel`, on by default; enabled only with AEC or `headset` in voice.json): Duck => new `Playback::set_duck(true)` (-12 dB, added to the audio crate), Restore, Stop => playback stopped + `VoiceEvent::BargeIn` -> `Input::BargeIn` (session goes Idle). Tests: VAD adaptation, session transition, dock. Not measured with real echo; quality of AEC unverified.
