Implemented in crates/app/src/organism_view/{mod,core,paint,geometry}.rs plus facade crates/app/src/ui/paint.rs (lyon_tessellation dep for round caps). Entity OrganismView owns a GPUI-free Core (Organism + inputs + DrawList + stats); canvas() paint steps, shapes and paints (prims -> PathBuilder fill/stroke + paint_path in order, custom dashing via geometry::dash_polyline, curves as quadratic splines, Discs as one path; text last via shape_line cached by text/size/weight/quantised colour). Consecutive paths are never interleaved with text so GPUI batches them in one path pass + one glyph pass. Frame loop: request_animation_frame while visible and active, inactive_frame_interval (default 100 ms) timer when not focused, nothing when hidden; observe_window_visibility resets the clock. Verified: cargo test -p app (52 pass incl. gpui_test painting), clippy -D warnings, xvfb screenshot (NVIDIA Vulkan): ~80 paint_path calls/frame, cpu p50 ~0.9 ms. Not verified: real hidden-window frame count on a compositor (Xvfb only).
