PipeWire host now default on Linux (960c458); device ids are prefixed pipewire:<node> (e.g. pipewire:alsa_input.usb-...), listed via audio::device::list_input_devices. Host can be forced with the existing host setting or PANDO_AUDIO_HOST. Still pending: macOS/Windows permission flows and physical hot-plug.
