Commit `feat(pando-stt): hands-free VAD segmentation and Whistle wake verification`. `pando_stt::vad`: `SpeechSegmenter` trait; `EnergySegmenter` (default, pure Rust, no model: 32 ms frames, adaptive noise floor +10 dB, 3-frame onset, 608 ms hangover, 320 ms pre-roll, min speech 256 ms, 30 s cap); `SileroSegmenter` behind cargo feature `silero-vad` (sherpa-onnx Silero v5; same TTS-off source build as `parakeet`, see PDA-T-0093 and scripts/build-sherpa-stt.sh; the prebuilt archives are forbidden in pando-stt by check-deps). Justification for the default: ADR 0005/0007 allow a single ONNX Runtime per process and no prebuilt sherpa in pando-stt, and the TTS-off source build is blocked locally by the GCC 11 issue, so the model-free energy VAD ships as default and Silero is opt-in. Protocol: voice-proto v2 adds `ToWorker::HandsFree{enabled,lang,keywords,sensitivity,vad_model}` / `Audio{pcm}` and `FromWorker::Utterance`; the worker answers with SpeechStart/SpeechEnd/WakeWord/Utterance; audio is only held in memory while a segment is open, never stored. Verification: 7 VAD unit tests (silence, burst with pre-roll/hangover, clicks dropped, chunk-size independence, long speech cut); idle proxy: 10 min of room noise through the energy VAD = 0.008 % of one core and the STT is never invoked (test asserts 0 calls); Silero via prebuilt libs (dev only) idle 0.157 %-0.18 % of a core. The app must stream 16 kHz mono blocks with `Audio`.
