Implemented `connection` module: ConnectionService on tokio (watch Snapshot for UI), states Connecting/Connected{version,project}/Unavailable{reason}/Unauthorized/TooOld{min,found}, health probe every 30 s (configurable) with immediate re-discovery when it fails, 1 s -> 30 s doubling backoff while disconnected, lenient version gate (default min 1.0.0, unparsable versions pass), credentials validated on connect via GET /api/v1/sessions?limit=1. Coordinated close/reopen: `Link::closed()` resolves when the generation ends; consumers call `service.link()` again. `nudge()` forces an immediate probe. Tests (short real intervals, mock servers that stop and restart on the same port): connect, stop => Unavailable + link closed, restart => Connected with new generation, too old, unauthorized, backoff recovery; live #[ignore] test connected to a real pando serve.
