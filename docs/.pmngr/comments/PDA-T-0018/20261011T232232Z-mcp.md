Spike S1 done on linux-x86_64. Report: `docs/spikes/S1-whistle.md`, code: `spikes/whistle-ffi/`, decision proposed in ADR 0008.

Findings:
- FFI: hand-written bindings (11 fns) + safe `!Send` wrapper. Static LLVM 21 libc++/libc++abi links with the default gcc linker; binary has no libc++.so dependency. Model load 12 ms.
- WER % (FLEURS es / MLS es / 150 synthetic commands): Whistle es 9.7 / 13.9 / 25.5 (17.9 with keyword bias, project-name recall 80 %); Parakeet v3 4.3 / 6.0 / 12.7 (recall 58 %); Whisper small 5.7 / 8.4 / 23.0.
- Latency P50/P95: Whistle 3 s 37/47 ms, 10 s 501/524 ms. **Cliff above 5 s** (74 ms at 5 s, 309 ms at 6 s). Parakeet 85/88 and 215/224 ms. Whisper small 607 ms and 2.6 s.
- Decision: conditional go. Whistle is the default for PTT commands (force language, keyword bias, ≤ 5 s segments, own process away from sherpa-onnx, see S3). Parakeet is the optional accuracy engine. Whisper is dropped.

Deviation: Common Voice was replaced by MLS Spanish test, because CV now needs a Mozilla Data Collective account and terms acceptance.

Pending (hardware/human): macos-arm64 link and latency run; command set recorded with real voices; CV es once terms are accepted. Leaving the task in_review.
