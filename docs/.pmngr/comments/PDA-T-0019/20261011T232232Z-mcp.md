Spike S2: cross-built on Linux and run under Wine 11. Report: `docs/spikes/S2-windows-stt-sidecar.md`, code: `spikes/whistle-ffi/src/bin/{pando-stt,stt-host}.rs`.

Findings:
- `x86_64-pc-windows-gnullvm` + llvm-mingw 20261006 (UCRT) links libneedle windows-x86_64 with static libc++/libc++abi/libunwind. The .exe imports only KERNEL32/ntdll/UCRT api-sets, with no extra DLLs to ship. It transcribes correctly under Wine.
- IPC overhead for a 5 s clip (320 KB frame, RTT minus engine time): P50 0.8–1.0 ms, P95 ≤ 2.3 ms, max ≤ 3.0 ms (Linux host to Wine sidecar, and Wine host to Wine sidecar). Pure-copy floor 0.08 ms. **Acceptance (< 20 ms) met.**
- Confirms ADR 0004 and ADR 0007; no new ADR.
