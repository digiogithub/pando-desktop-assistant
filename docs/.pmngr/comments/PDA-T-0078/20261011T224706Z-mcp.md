model done in pando-client (commit 7152829); view pending in app. `usage::UsageState` keeps every `token_usage` field (prompt, completion, cache read/creation, reasoning, cost, context window, estimated) and the session totals (Session now also carries CacheRead/CacheCreation/Reasoning tokens). Finding from the real fixtures: events are cumulative session totals; confirmed (`estimated:false`) ones equal the Session numbers, estimated ones interleave with cost 0. So `totals()` ignores estimates, `current()` shows a newer provisional reading flagged by `is_estimated()`. Accessible via `ChatModel::usage()`. The panel view remains.
