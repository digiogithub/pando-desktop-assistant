S7 analysis is in `docs/spikes/S7-espeak-ng-licence.md`. The decision is drafted as **ADR 0007 (status: proposed)**, `docs/adr/0007-espeak-ng-gpl-isolated-tts-worker.md`, and added to the ADR index.

Key finding: the single `pando-voice` worker in ADR 0004 cannot be distributed.
- It would link libneedle (closed source) together with espeak-ng (GPL-3.0+).
- GPL-3 §6 requires the Corresponding Source of the whole combined work, and libneedle's source is not available.

S3 also showed that any binary using the prebuilt sherpa-onnx static libs contains espeak-ng, even if it only uses VAD.

Proposed decision:
- Two workers:
  - `pando-tts`: sherpa-onnx TTS + espeak-ng, GPL-3, with a source offer per GPL-3 §6(d).
  - `pando-stt`: Whistle + VAD, permissive. Its VAD and fallback STT come from sherpa-onnx built from source with `SHERPA_ONNX_ENABLE_TTS=OFF`.
- The app stays MIT, with stdio IPC at arm's length.
- An own Spanish G2P stays a later hardening option.

Sources cross-checked:
- GPL-3 text §5 and §6
- FSF GPL FAQ: `#GPLStaticVsDynamic`, `#MereAggregation`, `#GPLPlugins`
- espeak-ng README (licence statement)
- piper1-gpl relicensing (it embeds espeak-ng)

README § License is not edited yet. It needs `pando-voice` → `pando-tts`/`pando-stt` once the ADR is accepted.
