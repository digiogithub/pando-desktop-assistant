Barge-in: `VoiceService::press` stops playback first when speaking (barge_in flag), `Session` emits StopAudio and the assistant cancels the synthesis of the interrupted utterance (the rest of the queue resumes); a new prompt while a run is active goes in as steering (`PandoClient::steer`). Window button/F9 and global PTT (shell `Output::Ptt` -> `voice::controller::ptt_edge`). Unit tests only; the < 50 ms stop was measured in the audio crate (6-29 ms), not end to end.
