Implemented in organism_view/mod.rs + core.rs: on_mouse_move -> pointer (px relative to the centred square, normalised in Core::advance), hover cursor pointer from semantics().hovered, click -> Organism::hit_test -> OrganismEvent::CellSelected / Deselected, keyboard via actions (Tab/Shift-Tab/arrows cycle, Home/End, Enter/Space select, Esc deselect; Tab past the ends releases focus to the next widget; bound with organism_view::bind_keys, called from app::start) with a focus ring painted on the focused cell. A11y: every cell has an overlay div with Role::Button, aria_label "<label>, <engine>, <estado>" (locale organism.cell.aria) and aria_selected; the canvas is a Role::Group. Verified with xdotool on xvfb (click selects, keys 1-5 and Tab ring work), unit tests for focus cycling. Not verified with a real screen reader.
