Report: docs/spikes/T-0026-global-hotkey-and-tray.md. Verified: global-hotkey on X11 gives Pressed/Released into the GPUI foreground pump (~150 us); ksni tray registers on COSMIC and Activate/menu events reach GPUI. COSMIC has no GlobalShortcuts portal (ashpd path compiles, degrades cleanly). Key finding: ashpd default `tokio` feature conflicts with GPUI's `async-io` (compile_error) so use default-features=false + async-io for ashpd and ksni. Sway/Wayland fallback: CLI --ptt-start/--ptt-stop documented. PENDING: hold-to-talk on macOS, Windows, KDE 6, GNOME 48+ portal; tray-icon on macOS/Windows.
